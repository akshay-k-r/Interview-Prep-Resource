# Concurrency in Python

This section covers the concurrency models, primitives, and frameworks in Python. Developers must understand when to apply multi-threading, multi-processing, and asynchronous execution (asyncio) depending on whether tasks are CPU-bound or I/O-bound.

## Topics

- [Threads & GIL](topic:threads-gil): Standard multithreading, mutexes, variables, and the CPython Global Interpreter Lock.
- [Multiprocessing](topic:multiprocessing): True parallel execution, Inter-Process Communication (IPC), and shared state.
- [Asyncio & Coroutines](topic:asyncio-coroutines): Event loops, coroutines, async/await, and cooperative multitasking.
- [Pools & Futures](topic:pools-futures): Thread/Process pools, execution management, and future callbacks.
